## 🗂️ البيانات والمصادر

- **التفاسير الأربعة** + **غريب الكلمات** + **الإعراب** — من **مركز تفسير للدراسات القرآنية**
- رخصة المحتوى: **CC BY 4.0**
- التغطية: **6,236 آية** كاملة (القرآن كاملاً)
- غريب الكلمات يغطي **كل كلمات القرآن** (77,432 من 77,433)

| الملف | المحتوى | الحجم |
|---|---|---|
| `data/index.json` | فهرس الآيات (بحث + مواضع) | 1.6MB |
| `data/tafsir.json` | التفسير الميسر | 2.5MB |
| `data/tafsir-saadi.json.gz` | تفسير السعدي (مضغوط) | 2.0MB |
| `data/tafsir-ibnkathir.json.gz` | تفسير ابن كثير (مضغوط) | 5.0MB |
| `data/tafsir-mukhtasar.json.gz` | التفسير المختصر (مضغوط) | 538KB |
| `data/gharib.json` | غريب الكلمات `[موضع، المعنى الكامل]` | 1.3MB |
| `data/irab/` | الإعراب (15 ملفاً — جزء لكل ملف) | — |

> التفاسير المضغوطة تُفك تلقائياً في المتصفح عبر `DecompressionStream('gzip')`.

## 🚀 التشغيل المحلي

```bash
cd "الباحث القرآني - GitHub"
python3 -m http.server 8000
```

ثم افتح: `http://localhost:8000`

> ⚠️ **لا تفتح index.html مباشرة (file://)** — المتصفح يمنع قراءة ملفات JSON من الملف المباشر.

## 🌐 الرفع على GitHub Pages

1. أنشئ مستودعاً على GitHub (مثال: `tafsir-search`)
2. ارفع كل الملفات مع الحفاظ على البنية:
   ```
   index.html
   css/style.css
   js/app.js
   js/search-engine.js
   sw.js
   manifest.json
   og-image.png
   icons/           ← icon-192، icon-512، apple-touch-icon
   fonts/           ← خط أميري + ثمانية
   data/            ← كل ملفات البيانات (كما هي)
   ```
3. فعّل **GitHub Pages** من Settings ← Pages ← فرع `main`
4. موقعك: `https://<username>.github.io/tafsir-search/`

```
├── og-image.png          ← صورة المشاركة (واتساب/تيليجرام)

```

## 🧰 التقنيات

- HTML/CSS/JavaScript خالص — **بدون مكتبات خارجية**
- Service Worker — كاش ذكي (الواجهة Network-First، البيانات Stale-While-Revalidate)
- Gzip للتفاسير الكبيرة + فك ضغط في المتصفح
- خط **Amiri** للآيات + خط **Thmanyah Serif** للواجهة
- RTL كامل + ثيمات CSS Variables
